# КОТИССИМО — сайт котокафе

Одностраничный сайт котокафе «Котиссимо» в Москве (Новая Басманная, 31с1).

Чистый HTML + CSS + немного JavaScript, без сборки и зависимостей — достаточно открыть `index.html` в браузере.

## Разделы сайта

- Первый экран со слайдером фотографий котиков
- О нас и статистика
- Цены и скидки
- Полезные статьи о здоровье кошек (ссылки на научные публикации)
- Правила посещения
- Акции
- Контакты

## Адаптивность

Вёрстка «резиновая» (fluid): размеры шрифтов и отступов заданы через `clamp()` и проценты, поэтому сайт плавно подстраивается под любую ширину окна и масштаб браузера (Ctrl + колесико, pinch-zoom на телефоне). Media-запросы используются только для перестройки раскладки на узких экранах.

## Структура

```
index.html        — главная (и единственная) страница
kotissimo_logo.png — логотип (используется и как favicon)
yellow-brush.svg  — текстура подложки заголовка
фон 2.jpg         — фоновое изображение сайта
фото котиков/     — фотографии для слайдера первого экрана
Болезни/          — изображения карточек статей
```

## Публикация на GitHub Pages

1. Создайте новый репозиторий и загрузите в него содержимое этой папки.
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
